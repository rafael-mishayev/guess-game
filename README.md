# Guess Game

A small terminal guessing-game collection written in Python.

## Games

- **Number Guessing** — the computer picks a number between 1 and 100, you guess it with higher/lower hints.
- **Word Guessing (Hangman)** — guess a hidden word one letter at a time with a limited number of wrong guesses.

## Run

```bash
python main.py
```

Follow the on-screen menu to pick a game. Your score is tracked for the session.

## Test

```bash
python -m unittest test_games.py
```
